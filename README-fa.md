# iran-mcp-router

**این تسک به کدوم سرور iran-mcp نیاز داره؟ از روتر بپرس، نه از کاتالوگ.**

[English](README.md)

</div>

پروژه‌ی [iran-mcp](https://github.com/sepehr071/iran-mcp) وب ایران رو به ایجنت‌های
هوش مصنوعی می‌ده: ۷۱ سرور MCP و ۸۸۳ ابزار -- قیمت ترب، آگهی‌های دیوار، بورس
TSETMC، طلا و ارز TGJU، اسنپ‌فود، دکترهای پذیرش۲۴، بلیط، نقشه، خبر و خیلی بیشتر.
ولی هیچ ایجنتی نمی‌تونه ۸۸۳ ابزار رو حفظ باشه، و حدس زدن سرور درست هم کانتکست
هدر می‌ده هم غلط درمیاد.

`iran-mcp-router` یه روتر کوچیک و قطعیه: تسک رو به فارسی یا انگلیسی می‌دی، سرور
درست + ابزاری که اول باید صدا بزنی + دستور نصب رو پس می‌گیری. یه فراخوانی ارزون
به‌جای خوندن کل کاتالوگ.

```bash
$ python3 scripts/router_cli.py "قیمت سکه امامی"
[6] tgju-mcp — TGJU Prices (prices)
    tool:    tj_get_prices
    install: uvx tgju-mcp
    repo:    https://github.com/sepehr071/tgju-mcp
    why:     کلیدواژه: سکه
```

## چطور کار می‌کنه

۱. **نرمالایز فارسی** (فقط stdlib): ي/ك عربی ← ی/ک فارسی، ارقام فارسی ← انگلیسی،
   نیم‌فاصله حذف می‌شه؛ پس «مي‌خوام» و «میخوام» یکی حساب می‌شن.
۲. **امتیاز کلیدواژه**: کلیدواژه‌ی هر سرور وزن ۳، اسم سرور وزن ۴، کلیدواژه‌ی
   دسته‌بندی وزن ۱. تطبیق با مرز کلمه انجام می‌شه -- «ارز» داخل «ارزون» گیر نمی‌کنه.
۳. **انتخاب ابزار بر اساس نیت**: «ارزون‌ترین گوشی» ← `tb_cheapest` نه فقط
   `tb_search`؛ «تاریخچه قیمت» ← ابزار تاریخچه.
۴. قطعیه: یه ورودی همیشه یه خروجی می‌ده، و هر نتیجه دلیلش رو هم داره
   (کدوم کلیدواژه‌ها خوردن).

کاتالوگ (`data/catalog.json` با ۷۱ سرور و ۸۸۳ ابزار) با اسکریپت
`scripts/build_catalog.py` از `servers.json` عمومی iran-mcp ساخته می‌شه --
تک‌منبع، بدون ویرایش دستی، بدون اسم ابزارِ از خود درآورده.

## نصب

**Claude Code** (به‌صورت MCP سرور):

```json
{
  "mcpServers": {
    "iran-mcp-router": {
      "command": "python3",
      "args": ["/path/to/iran-mcp-router/mcp_server.py"]
    }
  }
}
```

نیاز به `pip install "mcp>=2.2,<3"` داره. بعد ابزار `route_task` رو صدا بزن.

**Claude.ai**: فایل `dist/iran-mcp-router-claude-ai.zip` رو به‌عنوان اسکیل آپلود کن.

**Cursor**: فایل `.cursor/rules/iran-mcp-router.mdc` همراه ریپوست -- به ایجنت
می‌گه قبل از حدس زدن، روت کن. کپیش کن توی `.cursor/rules/` پروژه‌ت.

**Windsurf / Cline / Continue**: کانفیگ MCP بالا (هر MCP کلاینتی کار می‌کنه)،
یا ایجنت رو به `SKILL.md` ارجاع بده.

**بدون MCP؟** موتور فقط stdlib می‌خواد:

```bash
python3 scripts/router_cli.py "نوبت دکتر قلب در تهران"
```

## دموی وب

`index.html` رو باز کن -- دموی آفلاین، راست‌چین و فارسی با طراحی تیره.
تسک رو تایپ کن، کارت‌های رتبه‌بندی‌شده‌ی سرورها رو با دکمه‌ی کپی دستور نصب بگیر.
بدون هیچ درخواست خارجی.
